# Журнал рішень щодо стандарту кодування

Кожна зміна стандарту (нове правило, зміна рівня, придушення діагностики, скасування) фіксується записом `ADR-NNN` за процедурою розділу 7.3 `CODING_STANDARD.md`. Записи не редагують заднім числом: рішення, що змінює попереднє, — новий запис із посиланням на старий.

Стани: Запропоновано → Прийнято / Відхилено → (за потреби) Замінено ADR-NNN.

## ADR-001. Префікс `_` для всіх приватних полів, зокрема статичних.

- **Дата:** 21.11.2026.
- **Стан:** Прийнято.
- **Контекст:** Microsoft Learn і dotnet/runtime вимагають `s_` для статичних полів, StyleCop (SA1309) забороняє будь-яке підкреслення, а в коді вже є `private static readonly CultureInfo _culture`.
- **Варіанти:** (а) `s_` для статичних, `_` для решти — як у джерелах; (б) без префікса, з `this.` — як вимагає StyleCop; (в) `_` для всіх приватних полів.
- **Рішення:** варіант (в); SA1309 придушено.
- **Наслідки:** одне правило IDE1006 замість двох; обидва статичні поля проєкту вже відповідають; ціна — відступ від двох публічних настанов (див. 7.2).
- **Умова перегляду:** поява змінюваного статичного поля або багатопотокового коду.

## ADR-002. Округлення сум — `MidpointRounding.AwayFromZero`, перевірка скриптом.

- **Дата:** 21.11.2026.
- **Стан:** Прийнято.
- **Контекст:** під час запровадження стандарту знайдено шість викликів `Math.Round(x, 2)` без режиму — тобто з банківським округленням (до парного), тоді як рахунок клієнтові рахують «як у касі». Аналізатора, який вимагав би режим округлення, у .NET немає.
- **Варіанти:** (а) лишити за замовчуванням і задокументувати; (б) власний аналізатор Roslyn; (в) перевірка регулярним виразом у `tools/check-style.ps1`.
- **Рішення:** (в) — правило D-15 рівня ОБОВ’ЯЗКОВО; п’ять викликів (чотири політики ціноутворення й `RequestTotalCalculator`) виправлено одразу (усі 108 тестів лишилися зеленими), шостий у `WorkRequest` внесено до базового списку разом із боргом TD-08 до 18.12.2026.
- **Наслідки:** версія стандарту — 2.0.0 (нове ОБОВ’ЯЗКОВЕ правило).
- **Умова перегляду:** хибні спрацювання скрипту більше двох разів — тоді замінити регулярний вираз аналізатором.
