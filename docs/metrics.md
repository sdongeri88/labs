# Метрики успадкованого модуля (ЛР № 6)

Спосіб вимірювання: **вручну** за правилом методички, підрахунок звірено простим скриптом
(рядки, ключові слова розгалуження, дужки). Пакет Microsoft.CodeAnalysis.Metrics не
використовувався.

- LOC — рядки без порожніх і без рядків, що містять лише коментар;
- CC = 1 + кількість `if`, `else if`, `case`, `for`, `foreach`, `while`, `catch`, `&&`, `||`, `??`, `?:`
  (самостійний `else` не рахується);
- глибина вкладеності — найбільша кількість вкладених керуючих блоків у тілі методу.

### Розрахунок CC для Handle

| Точка розгалуження | Кількість |
|---|---|
| `if (lines != null)` | 1 |
| `if (lines.Count > 0)` | 1 |
| `if (state == "new" \|\| state == "paid")` та оператор `\|\|` | 2 |
| `if (clientMail != null && …)` та оператор `&&` | 2 |
| два цикли `for` | 2 |
| три перевірки виду клієнта (`if` / `else if` / `else if`) | 3 |
| три перевірки межі знижки `if (… > 500m)` | 3 |
| `if (сума < 1000m)` | 1 |
| `if (sendMail)` | 1 |
| **Разом точок розгалуження** | **16** |

CC = 1 + 16 = **17** — понад утричі більше за орієнтир «≤ 5».

### Додатково

- відповідальностей класу: **7** — перевірка вхідних даних, сума позицій, знижки, доставка,
  форматування звіту, журнал, опис клієнта;
- дубльованих рядків між Handle і Preview: **18** (знижка 16 + доставка 2);
- магічних чисел: **7** різних значень, **25** входжень.
