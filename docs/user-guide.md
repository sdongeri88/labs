# Посібник користувача TaskTracker

Коротка інструкція для людини, яка бачить застосунок уперше. Ідентифікатори UC-xx відповідають
сценаріям у [spec.md](spec.md).

## Запуск і перший екран

Потрібен .NET SDK 8.0. З кореня репозиторію:

    dotnet run --project src/TaskTracker.Cli

Одразу після запуску застосунок показує, де лежать дані, і меню. Вибір пункту — число й Enter.

```text
TaskTracker — дошка команди. Дані: data/board.json
1 — створити завдання (UC-01)
2 — перемістити завдання (UC-02)
3 — призначити виконавця (UC-03)
4 — знайти завдання (UC-04)
5 — звіт «завантаження виконавців» (UC-05)
6 — зберегти дошку (UC-06)
0 — зберегти й вийти
Ваш вибір: 1
```

## Прохідні сценарії

Нижче — фактичний вивід одного сеансу (ввід користувача стоїть після двокрапки). Цей самий сеанс
можна відтворити на свіжих умовних даних (без `data/board.json`):
`dotnet run --project src/TaskTracker.Cli < docs/session-input.txt` — файл містить введені рядки.

### 1. Створити завдання (UC-01)

Пріоритет — число 1–4 (1 — Critical) або назва, оцінка — години, дробова частина через кому чи
крапку. Виконавця можна не вказувати.

```text
Ваш вибір: 1
Назва (порожньо — скасувати): Підготувати демо для захисту
Пріоритет 1–4: 2
Оцінка, год: 3,5
Виконавець: nadia
Створено: #61  [Backlog   ] Підготувати демо для захисту (High, 3,5 год) @nadia
```

Якщо ввід некоректний, застосунок пояснює причину й повторно просить назву; порожня назва скасовує
створення:

```text
Ваш вибір: 1
Назва (порожньо — скасувати): Звіт
Пріоритет 1–4: 9
Оцінка, год: 1
Виконавець: 
Помилка вводу: Невідомий пріоритет «9».
Назва (порожньо — скасувати): 
```

### 2. Перемістити завдання дошкою (UC-02)

Колонки: Backlog, Todo, InProgress, Review, Done. Дозволені переходи й ліміти описано в розділах 1.4–1.5
специфікації. Чотири спроби поспіль: заборонений перехід, дозволений перехід, закриття перевіреного
завдання і відмова через ліміт WIP:

```text
Ваш вибір: 2
Номер завдання: 61
Колонка: Done
Відхилено: Перехід Backlog → Done заборонено для #61.
Ваш вибір: 2
Номер завдання: 61
Колонка: Todo
Переміщено: #61  [Todo      ] Підготувати демо для захисту (High, 3,5 год) @nadia
Ваш вибір: 2
Номер завдання: 6
Колонка: Done
Переміщено: #6   [Done      ] Прискорити імпорт учасників (High, 24 год) @ivan
Ваш вибір: 2
Номер завдання: 61
Колонка: InProgress
Відхилено: Колонка InProgress заповнена до ліміту WIP.
```

### 3. Призначити виконавця (UC-03) і знайти завдання (UC-04)

Порожній критерій пошуку не обмежує вибірку; результат упорядковано за пріоритетом, потім за номером.

```text
Ваш вибір: 3
Номер завдання: 31
Логін: maria
Призначено: #31  [Backlog   ] Додати експорт звіту в CSV (Normal, 4 год) @maria
Ваш вибір: 4
Виконавець: ivan
Колонка: 
Фрагмент назви: 
Знайдено: 5
#1   [InProgress] Додати експорт звіту в CSV (Critical, 4 год) @ivan
#9   [Todo      ] Оновити пошук за тегом (Critical, 12 год) @ivan
#17  [Done      ] Описати історію переміщень (Critical, 20 год) @ivan
#25  [Done      ] Додати журнал змін (Critical, 4 год) @ivan
#6   [Done      ] Прискорити імпорт учасників (High, 24 год) @ivan
```

### 4. Звіт «завантаження виконавців» (UC-05)

Завантаження = години активних завдань (InProgress і Review) ÷ тижнева місткість. Рівні: менше 50 % —
вільний, 50–100 % — нормально, понад 100 % — перевантажений.

```text
Ваш вибір: 5
Завантаження виконавців на 21.11.2026
Логін    Ім'я             Активних  Годин Місткість     %  Рівень
olena    Олена Кравець           2     12        10   120  ПЕРЕВАНТАЖЕНИЙ
petro    Петро Савчук            1     20        25    80  нормально
sofia    Софія Литвин            1     16        30    53  нормально
taras    Тарас Гнатюк            2     20        40    50  нормально
ivan     Іван Мороз              1      4        30    13  вільний
andrii   Андрій Бойко            0      0        30     0  вільний
maria    Марія Ткач              0      0        35     0  вільний
nadia    Надія Бондар            0      0        20     0  вільний
Завантаження команди: 33 %
```

### 5. Збереження й вихід (UC-06)

```text
Ваш вибір: 0
Дошку збережено.
```

## Повідомлення про помилки

| Повідомлення | Що означає | Що робити |
|---|---|---|
| `Помилка вводу: Назва не може бути порожньою.` | назву не введено | введіть назву або порожній рядок для скасування |
| `Помилка вводу: Невідомий пріоритет «9».` | пріоритет поза 1–4 | введіть 1–4 або Critical, High, Normal, Low |
| `Помилка вводу: Оцінка має бути від 0 до 80 год.` | від'ємна або завелика оцінка | розбийте велике завдання на кілька |
| `Помилка вводу: «abc» не є номером завдання.` | номер не є додатним числом | введіть номер із результатів пошуку |
| `Помилка вводу: Завдання #999 не знайдено.` | такого номера немає | знайдіть завдання через пункт 4 |
| `Помилка вводу: Невідома колонка «Archive».` | колонки немає | Backlog, Todo, InProgress, Review або Done |
| `Помилка вводу: Виконавця «x» немає в команді.` | логіна немає в довіднику | перевірте логін у звіті (пункт 5) |
| `Відхилено: Перехід Backlog → Done заборонено для #61.` | перехід відсутній у таблиці | рухайте завдання колонками по черзі |
| `Відхилено: Завдання #N без виконавця не можна взяти в роботу.` | InProgress потребує виконавця | спершу пункт 3 |
| `Відхилено: Колонка InProgress заповнена до ліміту WIP.` | у колонці вже максимум завдань | завершіть або поверніть одне з наявних |
| `Відхилено: У ivan уже максимум активних завдань.` | у виконавця 2 завдання в роботі й на перевірці | призначте іншого виконавця |
| `Відхилено: Завдання #N уже виконано, виконавця не змінюють.` | завдання в Done | змін не потрібно |
| `Не вдалося зберегти дошку: …` | файл даних недоступний для запису | закрийте програму, що тримає файл, і збережіть ще раз (пункт 6) |
| `Немає такого пункту меню, введіть число від 0 до 6.` | невідомий пункт | див. меню |

## Дані, журнал і резервна копія

- Дошка зберігається у `data/board.json` (відносно теки, з якої запущено застосунок). Якщо файлу немає,
  під час запуску створюються умовні дані: 8 вигаданих учасників і 60 завдань.
- Журнал роботи — `logs/tasktracker.log`, рядок «час;рівень;сценарій;повідомлення», наприклад
  `2026-11-21 02:47:06;Warning;UC-02;Операцію відхилено: ColumnLimitReached`. Імен і назв завдань у
  журналі немає, лише номери.
- Резервна копія — скопіюйте `data/board.json` при закритому застосунку. Відновлення — покладіть копію
  на місце. Щоб почати з умовних даних, видаліть файл.
