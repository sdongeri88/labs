## Три підсумкові числа

1. Виконано пунктів чекліста: 17 з 20 «так» = 85 %.
2. Покриття бібліотеки логіки: рядкове 94,9 %, гілок 89,7 %.
3. Залишковий технічний борг за пунктами «частково»: 1,5 год (TD-12 — 1 год, TD-13 — 0,5 год); пункт 19
   годинами не виправляється — історію комітів неможливо відновити заднім числом.

## Непокриті гілки бібліотеки логіки

| Місце | Гілка | Чому не покрито | Рішення |
|---|---|---|---|
| `TaskService.cs:24–27`, `MoveService.cs:24–27`, `WorkloadReportService.cs:19–21`, `WipMovePolicy.cs:15` | `?? throw new ArgumentNullException` у конструкторах | недосяжна в робочій програмі: усі залежності створює композиційний корінь; це захист від помилки програміста | лишити як запобіжник, тест не потрібен |
| `DomainException.cs:8–25`, `MoveRejectedException.cs:8–26` | стандартні конструктори без параметрів і з `innerException` | службові: їх вимагає правило CA1032 для власних винятків, код застосунку їх не викликає | лишити, тест не потрібен |
| `BoardTask.cs:109, 115` | гілка `_ =>` у `RejectionText` | недосяжна: метод викликається лише для рішення, відмінного від `Allowed`, а решту чотири рішення покрито | лишити як захисну гілку |
| `WipLimits.cs:59, 65` | гілка `_ => throw` у `ForColumn` | недосяжна для визначених значень `BoardColumn`; спрацює лише на числі поза переліченням (помилка програміста) | лишити, тест не потрібен |
| `TransitionTable.cs:24, 30` | `TryGetValue` повертає false | недосяжна: таблиця містить рядок для кожної з п'яти колонок | лишити як захисну перевірку |
| `MemberWorkload.cs:13` | властивість `Name` | її читає лише консольний звіт `WorkloadPrinter`, що поза межею вимірювання | поза межами вимірювання, перевірено вручну (посібник, UC-05) |
| `InputParser.cs:16`, `WorkloadCalculator.cs:10–15` | ініціалізація сталих `decimal` | артефакт вимірювання: `const decimal` компілятор перетворює на статичне поле, рядок оголошення coverlet рахує окремо; значення використовуються в покритих методах | пояснено, дій не потрібно |

Інфраструктура (`JsonBoardRepository`, `FileLoggerProvider`, `SystemClock`) і консоль (`TaskTracker.Cli`)
до знаменника не входять за рішенням DR-07; сховище JSON додатково перевіряють 3 тести, журнал і
консоль — прохід посібника користувача.

## Три найслабші місця

| Місце | Наслідок, якщо знехтувати | Оцінка виправлення |
|---|---|---|
| Історія комітів СР3 за один день | процес поступового конструювання не видно з історії; пункт 19 чекліста й частина оцінки втрачаються | не виправляється заднім числом; на майбутнє — коміт щонайменше щодня роботи |
| Файл дошки без блокування від одночасного запуску (TD-14) | дві копії застосунку перезапишуть зміни одна одної — втрата даних без повідомлення | 2 год: ексклюзивне відкриття файлу або перевірка дати зміни перед записом |
| Журнал без ротації (TD-12) | за місяці роботи файл `logs/tasktracker.log` росте без меж і займає диск | 1 год: новий файл щодня або обрізання за розміром у `FileLoggerProvider` |
